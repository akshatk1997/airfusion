## 🎯 Platform Vision & Core Promise

Raw air quality index numbers (e.g. *"AQI 142"* or *"PM₂.₅ 58.4 µg/m³"*) present an interpretative challenge for non-technical individuals:
- *"Is it safe for my child to play outdoors right now?"*
- *"When is the cleanest, lowest-pollution window for a 45-minute jog?"*
- *"Do I need to wear an N95 respirator or run an indoor air purifier?"*
- *"Why does air quality plummet in the early morning despite low traffic?"*

At the same time, environmental engineers, atmospheric researchers, and policy directors require rigorous mathematics, dispersion modeling, boundary layer thermodynamics, metrological sensor hygroscopy corrections, and statutory compliance frameworks.

**AirGuard resolves this dichotomy through a synchronized Dual-Experience Engine.** The exact same underlying multi-pollutant telemetry feeds two parallel, specialized interfaces:
- **Simple Mode**: Translates complex physics into human-first analogies, 3D animated guardian sentries with live mood reactivity, child-friendly storybooks, and plain-language action directives.
- **Technical Mode**: Unlocks an institutional-grade analytical workbench with 7 interactive mathematical instruments, SVG sounding profiles, Gaussian plume dispersion curves, and live developer API code generation.

### Tool 1: 🌬️ Gaussian Plume Atmospheric Dispersion Simulator
- **Analytical Ground-Level Formulation**: Steady-state continuous point-source plume dispersion with total ground reflection ($z = 0$):
  $$C(x, y, 0) = \frac{Q}{\pi u \sigma_y \sigma_z} \exp\left(-\frac{y^2}{2\sigma_y^2}\right) \exp\left(-\frac{H^2}{2\sigma_z^2}\right) \times 10^6 \quad (\mu\text{g/m}^3)$$
- **Pasquill-Gifford Stability Spectrum (A–F)**:
  - **Class A**: Extremely Unstable (Intense convective thermals, rapid plume spread)
  - **Class B**: Moderately Unstable (Daytime insolation)
  - **Class C**: Slightly Unstable (Transitional convective)
  - **Class D**: Neutral (Overcast skies or heavy mechanical wind shear)
  - **Class E**: Slightly Stable (Nocturnal radiative surface cooling)
  - **Class F**: Moderately Stable (Severe nocturnal surface inversion trap)
- **Briggs Rural Parameterization**: Dynamically computes $\sigma_y(x)$ and $\sigma_z(x)$ down to sub-meter accuracy.
- **Interactive Control Sliders**: Emission mass rate $Q$ ($10 - 500\text{ g/s}$), stack height $H$ ($10 - 250\text{ m}$), wind speed $u$ ($1.0 - 20.0\text{ m/s}$), downwind distance $x$ ($100 - 10,000\text{ m}$), and crosswind lateral offset $y$ ($0 - 500\text{ m}$).
- **Dynamic Interactive SVG Chart**: Renders the complete ground concentration curve $C(x, 0, 0)$ across $0$ to $10\text{ km}$, marks peak concentration $C_{\max}$ and touchdown distance $x_{\max}$, and highlights receptor crosshair coordinates.

---

### Tool 2: 📐 EPA & CPCB Multi-Pollutant AQI Sub-Index Resolver
- **Piecewise Linear Interpolation Algorithm** (US EPA 40 CFR Part 58 & CPCB National Standard):
  $$I_p = \left\lfloor \frac{I_{\text{Hi}} - I_{\text{Lo}}}{BP_{\text{Hi}} - BP_{\text{Lo}}} (C_p - BP_{\text{Lo}}) + I_{\text{Lo}} \right\rceil$$
- **Real-Time Criteria Pollutant Matrix**: Evaluates observed concentrations across all 6 criteria pollutants ($\text{PM}_{2.5}, \text{PM}_{10}, \text{NO}_2, \text{SO}_2, \text{O}_3, \text{CO}$), displaying active breakpoint intervals $[BP_{\text{Lo}}, BP_{\text{Hi}}]$, corresponding sub-index intervals $[I_{\text{Lo}}, I_{\text{Hi}}]$, and individual calculated AQI values.
- **Critical Pollutant Identifier**: Dynamically identifies and badges the **Critical Pollutant** ($I_{\max} = \max_p I_p$) dictating the airshed's official AQI.
- **Interactive Breakpoint Bench**: Allows engineers to input arbitrary concentrations for any pollutant to inspect the interpolation slope $m$, offset delta, and resulting category.

---

### Tool 3: 🌡️ Planetary Boundary Layer & Thermodynamic Profiler
- **Thermodynamic Equations**:
  - **Potential Temperature**: $\theta = (T + 273.15) \left(\frac{1000}{P}\right)^{0.286} - 273.15 \quad (°\text{C})$
  - **Saturated Vapor Pressure**: $e_s = 6.112 \exp\left(\frac{17.67 T}{T + 243.5}\right) \quad (\text{hPa})$
  - **Specific Humidity**: $q = \frac{0.622 e}{P - 0.378 e} \quad (\text{kg/kg})$
  - **Virtual Temperature**: $T_v = (T + 273.15)(1 + 0.61 q) - 273.15 \quad (°\text{C})$
  - **Bulk Richardson Number**:
    $$Ri_b = \frac{g}{\theta_{v,\text{sfc}}} \frac{\Delta T \cdot (H_{\text{PBL}} / 2)}{U_{10}^2}$$
  - **Ventilation Coefficient**: $V_c = H_{\text{PBL}} \times U_{10} \quad (\text{m}^2/\text{s})$
- **Atmospheric Boundary Layer Diagnostics**: Classifies the layer into **Convectively Unstable** ($Ri_b < 0$), **Neutral / Shear-Controlled** ($0 \le Ri_b \le 0.25$), or **Critical Thermal Inversion Trapping** ($Ri_b > 0.25$).
- **SVG Sounding Diagram**: Plots ambient environmental temperature against the Dry Adiabatic Lapse Rate ($\text{DALR} = 9.8\,°\text{C/km}$), displaying the exact capping lid height.

---

### Tool 4: 🛰️ Satellite Spectrometry, AOD & Ångström Exponent Analyzer
- **Optical Multi-Band Extinction**:
  - **Ångström Turbidity Exponent**:
    $$\alpha = -\frac{\ln(\tau_{440} / \tau_{870})}{\ln(440 / 870)} = \frac{\ln(\tau_{440}) - \ln(\tau_{870})}{0.6817}$$
  - **Extrapolated Green AOD (550nm)**: $\tau_{550} = \tau_{440} \times \left(\frac{550}{440}\right)^{-\alpha}$
  - **Aerosol Absorbing Index (AAI)**: $\text{AAI} = (1 - \omega_0) \times \tau_{550} \times 14.0$
- **Microphysical Size Classification**:
  - $\alpha \ge 1.5$: **Fine-Mode Combustion Soot** (Hydrocarbon combustion, diesel exhaust, agricultural biomass burning)
  - $0.8 \le \alpha < 1.5$: **Mixed Urban-Industrial Polydisperse** (Aged urban smog, sulfate/nitrate condensation)
  - $\alpha < 0.8$: **Coarse Crustal Particulate** (Thar & Saharan mineral dust storms, crustal abrasion)
- **Radiative Forcing State**: Evaluates Single Scattering Albedo ($\omega_0$) to distinguish atmospheric warming (black carbon absorption) from surface cooling (sulfate scattering).

---

### Tool 5: ⚙️ Sensor Metrology & Köhler Hygroscopic Growth Bench
- **Köhler Deliquescence Swelling Model**: Solves the overestimation bias of optical particle counters (OPCs like Plantower PMS5003 and Sensirion SPS30) caused by water condensation on soluble salts:
  $$f(\text{RH}) = 1 + a \left(\frac{\text{RH}}{100 - \text{RH}}\right)^b$$
  $$C_{\text{true}} = \max\left(0.1, \frac{C_{\text{raw}} - \Delta Z_0}{S_f \cdot f(\text{RH})}\right)$$
- **Interactive Metrological Knobs**: Raw sensor reading ($C_{\text{raw}}$), ambient relative humidity ($\text{RH}$), deliquescence parameters ($a, b$), zero baseline offset ($\Delta Z_0$), and span sensitivity multiplier ($S_f$).
- **Metrological Diagnostics**:
  - Side-by-side **Raw OPC Signal** vs **Calibrated Gravimetric Reference**
  - Liquid water accretion mass artifact ($\Delta C_{\text{water}}$ in $\mu\text{g/m}^3$)
  - Percentage moisture inflation gauge ($+X\%$).

---

### Tool 6: 🏛️ Statutory Mitigation Decision Engine & CAQM GRAP Matrix
- **Statutory Framework**: Grounded in Section 12 of the Commission for Air Quality Management (CAQM) Act 2021 & US EPA 40 CFR Part 58 emergency guidelines.
- **Automated Stage Determination**: Evaluates live city telemetry or custom simulated AQI into:
  - **Baseline** ($\text{AQI} \le 200$): Preventive road sweeping, mechanical dust suppression
  - **Stage I: Poor** ($\text{AQI } 201 - 300$): Water sprinklers, anti-smog guns on construction sites $>500\text{ m}^2$, PUC audits
  - **Stage II: Very Poor** ($\text{AQI } 301 - 400$): Prohibition on Diesel Generator (DG) sets, $2\times-4\times$ parking fee hikes, uninterrupted municipal grid power
  - **Stage III: Severe** ($\text{AQI } 401 - 450$): Complete shutdown of non-essential construction & demolition (C&D), ban on BS-III petrol & BS-IV diesel light motor vehicles, primary school online transition
  - **Stage IV: Severe+** ($\text{AQI} > 450$): Ban on heavy diesel commercial trucks, complete halt on public infrastructure works, mandatory 50% Work-From-Home (WFH), odd-even vehicular rationing readiness
- **Interactive Municipal Field Checklist**: Allows inspectors and field engineers to check off mandatory statutory compliance items.

## 🫁 Clinical Dosimetric Respiratory Models

Technical Mode expands the [My Safe Outdoor Plan](https://airgd.vercel.app) module into a clinical dosimetric workstation:
- **Minute Ventilation Formulation**:
  $$V_E = V_T \times f_R \times \left(\frac{\text{MET}}{1.0}\right) \quad (\text{L/min})$$
- **Total Inhaled Particulate Mass**:
  $$M_{\text{inhaled}} = V_E \times t \times \left(\frac{C_{\text{PM2.5}}}{1000}\right) \quad (\mu\text{g})$$
- **Alveolar Deposition**: Estimates alveolar mass accumulation using a calibrated $35.2\%$ tracheobronchial penetration fraction.
- **Muller-Berkeley Cigarette Equivalence**: Quantifies particulate burden against cigarette consumption ($1\text{ cigarette} \approx 22\,\mu\text{g PM}_{2.5}$):
  $$N_{\text{cig}} = \frac{M_{\text{inhaled}}}{22.0}$$
- **Macrophage Phagocytic Clearance**: Models physiological pulmonary clearance half-life ($T_{1/2} \approx 48-72\text{ hours}$).
- **PPE Respiratory Ingress Comparison**: Side-by-side inhaled mass reduction across **Unfiltered**, **Surgical Mask (35% eff)**, **N95 / FFP2 (95% eff)**, and **N99 / FFP3 (99% eff)**.

## 🤖 Machine Learning Ensemble Architecture

AirGuard deploys a gradient-boosted regression tournament on multi-month historical archives:

| Model Architecture | Objective Function | Loss Formulation | Cross-Validated $R^2$ Score | Holdout Test RMSE ($\mu\text{g/m}^3$) | Inference Latency |
|---|---|---|:---:|:---:|:---:|
| **LightGBM (Champion)** | Gradient Boosting | Huber Loss ($\delta = 1.35$) | **0.941** | **8.42** | **14.2 ms** |
| **XGBoost Regressor** | Tree Booster | `reg:pseudohubererror` | 0.938 | 8.85 | 16.5 ms |
| **CatBoost Regressor** | Symmetric Trees | RMSE / MAE | 0.932 | 9.12 | 19.1 ms |
| **Random Forest** | Bagging Ensemble | MSE | 0.884 | 12.30 | 45.0 ms |
| **Ridge Regression** | L2 Regularized | Least Squares | 0.745 | 18.50 | 2.1 ms |

- **Feature Engineering Pipeline**: 1-hour, 2-hour, 3-hour, 6-hour, 12-hour, and 24-hour autoregressive lag features; 3h/6h/12h/24h rolling means and standard deviations; cyclical hour-of-day ($\sin / \cos$) encodings; and boundary layer ventilation indices.
- **Data Leakage Prevention**: Strict chronological partitioning ($70\%$ train, $15\%$ validation, $15\%$ holdout test).

## 🚀 Quickstart & Local Installation

### Prerequisites
- Python 3.10, 3.11, 3.12, or 3.14
- Git

### 1. Clone & Setup Environment
```bash
git clone https://github.com/akshatk1997/airguard.git
cd airguard

# Create and activate virtual environment
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Install dependencies
pip install --upgrade pip
pip install -r requirements.txt
```

### 2. Launch Local Servers
```bash
# Option A: Run Streamlit Application
python -m streamlit run airguard/app/Home.py

# Option B: Run Standalone Web App
npx serve public
```
